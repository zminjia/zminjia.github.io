# 贴图 · DaJia 的表情包图库

一个极简风格的贴图 / 表情包作品集：白底、大留白，一次专心看一张。纯静态站点（HTML / CSS / 原生 JS），没有构建步骤，由 GitHub Pages 从默认分支根目录直接发布。

在线浏览：<https://zminjia.qzz.io>（`zminjia.github.io` 会自动跳转过来）

## 特点

- **大图优先**：当前作品居中放大，至少占半屏；标题、日期和标签放在图下方。
- **左右切换**：大图两侧的 ‹ › 箭头切换到相邻作品，首尾循环；也可以用键盘 ← / →，或在手机上左右滑动。
- **作品时间线**：底部一排缩略图，按日期排列，点击即可跳转，当前作品高亮并自动滚到可见位置。
- **EVA 风格字体**：标题用思源宋体（Noto Serif SC）最粗字重，压窄、收紧字距，致敬《新世纪福音战士》的马蒂斯明朝体。
- **深色模式**：左下角「深色 / 浅色」切换；没手动选过时跟随系统设置。
- **图片保护**：禁用右键、拖拽和手机长按保存，大图右下角叠加半透明「DaJia」水印（只是叠加层，原图文件不变）。
- **可分享链接**：选中的作品会写进地址栏 `#work=id`，刷新或分享后仍停在这一张。

## 目录结构

```
index.html        页面
css/style.css     样式
js/app.js         读取数据、渲染大图与时间线、切换、深色模式、图片保护
data/works.json   作品列表（页面唯一数据源）
images/           每件作品一张图片（通常是 1080×1080 透明底 WebP）
CNAME             自定义域名 zminjia.qzz.io
.nojekyll         关闭 Jekyll 处理
```

页面启动时读取 `data/works.json`，完全根据这份 JSON 渲染，默认选中最新的一件。

## 添加一件作品

1. 把图片放进 `images/`，例如 `images/cat-wave.webp`。推荐 1080×1080、透明背景的 WebP；PNG / GIF / JPG 也可以。
2. 在 `data/works.json` **数组最前面**插入一条（按日期从新到旧）：

```json
{
  "id": "cat-wave",
  "file": "images/cat-wave.webp",
  "title": "挥手猫",
  "tags": ["猫", "日常"],
  "date": "2026-10-10"
}
```

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一标识，建议和文件名一致（不含扩展名），会出现在 `#work=` 链接里 |
| `file` | 相对站点根目录的图片路径 |
| `title` | 显示的标题 |
| `tags` | 标签数组，显示在标题下方的日期后面 |
| `date` | `YYYY-MM-DD` |

3. 提交并推送到默认分支，GitHub Pages 部署完成后（通常一两分钟）就能在网站上看到。

## 本地预览

浏览器在 `file://` 下会拦截读取 JSON，所以需要起一个静态服务器：

```bash
python3 -m http.server 8080
```

然后打开 <http://localhost:8080>。

## 作品从哪里来

原图放在 Google Drive 的 `grokbot/表情包/原图`，做成贴图后放进 `grokbot/表情包/贴图`，只有 `贴图` 里做好的作品才会上网站。每次上新都会先在单独的分支上做预览，确认后再合并到默认分支上线。
